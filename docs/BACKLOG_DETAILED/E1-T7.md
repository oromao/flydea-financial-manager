# E1-T7 — Dialog Mobile com Header Sticky

## Identificação

- **ID:** E1-T7

- **Título:** Dialog mobile com header sticky (M-01)
- **Prioridade:** P0 (Crítico)
- **Complexidade:** Baixa

---

## Problema/Oportunidade

**Gap:** M-01

Na página de Movimentações (`/movimentacoes`), o dialog de criar/editar transação no mobile é fullscreen (`h-[100dvh]`) mas **não tem header fixo**. O botão de fechar rola para fora da tela quando o usuário scrolla o formulário.

**Impacto:** Usuário fica "preso" no formulário sem poder fechá-lo facilmente após scrollar.

---

## Objetivo

Adicionar header sticky com botão de fechar sempre visível no dialog mobile.

---

## Descrição

1. **Verificar:** Dialog component em `src/components/ui/dialog.tsx`
2. **Em `/movimentacoes/page.tsx`** (dialog content), adicionar:
   ```tsx
   <div className="sticky top-0 z-10 bg-surface flex justify-between items-center p-4">
     <h2>{isEditing ? "Editar Transação" : "Nova Transação"}</h2>
     <Button variant="ghost" size="icon" onClick={close}>
       <X className="w-5 h-5" />
     </Button>
   </div>
   ```
3. **Ou:** Modificar o Dialog component para suportar header sticky via props

---

## Valor para o Negócio

UX premium no mobile — usuário nunca fica "preso" no formulário.

---

## Impacto no Usuário

- Fecha formulário mobile a qualquer momento
- Mesmo após rolar para baixo
