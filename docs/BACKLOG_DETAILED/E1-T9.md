## Problema/Oportunidade

**Gap:** M-09

O botão FAB (Floating Action Button) de criar nova transação está posicionado em `bottom-24` (96px). Em dispositivos com safe-area-inset grande (iPhone 16 com notch e home indicator), o FAB pode sobrepor ou ficar muito próximo da bottom navigation.

**Impacto:** Toques acidentais no FAB ou na bottom nav, frustração.

---

## Objetivo

Ajustar posição do FAB para considerar `env(safe-area-inset-bottom)`.

---

## Descrição

1. **Local:** `src/app/movimentacoes/page.tsx`
2. **Modificar** a classe do FAB:
   ```tsx
   // De:
   className="fixed bottom-24 ..."
   
   // Para:
   className="fixed bottom-[calc(4rem+env(safe-area-inset-bottom)+16px)] ..."
   ```
3. **Verificar** se outros FABs no projeto têm o mesmo problema

## Cálculo do Offset

```
bottom = bottom-nav-height + safe-area-inset-bottom + gap
       = 4rem (64px) + env(safe-area-inset-bottom) + 16px (1rem)
       = calc(4rem + env(safe-area-inset-bottom) + 1rem)
       = calc(5rem + env(safe-area-inset-bottom))
```

Ajustar conforme necessidade de gap visual.
