# E1-T3 — Definir glass-card no globals.css

## Identificação

- **ID:** E1-T3
- **Tipo:** Bug 🔴
- **Módulo:** UI / Design System
- **Título:** Definir `glass-card` no globals.css (DS-05, DS-10)
- **Prioridade:** P0 (Crítico)
- **Complexidade:** Baixa

---

## Problema/Oportunidade

**Gaps:** DS-05, DS-10

A classe CSS `.glass-card` é usada nos componentes:
- `src/components/ui/empty-state.tsx` — `className="glass-card rounded-[32px] p-12"`
- `src/components/ui/confirm-dialog.tsx` — `className="glass-card rounded-3xl p-6"`

Mas `.glass-card` **não está definida** no globals.css. Resultado: componentes renderizam sem o estilo esperado.

**Impacto:** UI quebrada em EmptyState e ConfirmDialog — aparência diferente do planejado.

---

## Objetivo

Definir a classe `.glass-card` no globals.css ou substituir por uma classe existente (`premium-card`).

---

## Descrição

1. **Verificar** se `.premium-card` existe e tem estilo similar
2. **Se existir:** Substituir `glass-card` por `premium-card` em ambos componentes
3. **Se não existir:** Definir `.glass-card` no globals.css com:
   - background translúcido
   - border-radius generoso
   - backdrop-filter (glass effect sutil)
   - sombra suave

---

## Valor para o Negócio

Evita UI quebrada em componentes críticos — Empty States e Confirmações são pontos de contato frequentes.

---

## Impacto no Usuário

- EmptyState renderiza com estilo premium
- ConfirmDialog renderiza com estilo premium
