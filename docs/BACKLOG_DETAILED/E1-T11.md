## Problema/Oportunidade

**Gap:** DS-02

O Dialog component no mobile (fullscreen) não tem gesture de swipe-down para fechar. Usuário precisa rolar até o topo para encontrar o botão X ou usar o botão nativo do OS.

**Impacto:** Experiência abaixo do premium — gesto intuitivo ausente.

---

## Objetivo

Adicionar drag gesture via Framer Motion para swipe-down-to-close no Dialog mobile.

---

## Descrição

1. **Local:** `src/components/ui/dialog.tsx`
2. **Adicionar** Framer Motion drag ao Dialog Content:
   ```tsx
   import { motion } from "framer-motion";
   
   <motion.div
     drag="y"
     dragConstraints={{ top: 0, bottom: 0 }}
     dragElastic={0.2}
     onDragEnd={(e, { offset, velocity }) => {
       if (offset.y > 100 || velocity.y > 500) {
         onOpenChange(false);
       }
     }}
   >
     {/* Dialog content */}
   </motion.div>
   ```
3. **Adicionar** indicator visual de swipe (linha no topo)
4. **Testar** em múltiplos dispositivos
