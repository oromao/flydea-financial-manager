# E1-T4 — Definir --color-muted no tema

## Identificação

- **ID:** E1-T4
- **Tipo:** Bug 🔴
- **Módulo:** UI / Design System
- **Título:** Definir `--color-muted` no tema Tailwind (DS-08)
- **Prioridade:** P0 (Crítico)
- **Complexidade:** Baixa

---

## Problema/Oportunidade

**Gap:** DS-08

O componente `src/components/ui/skeleton.tsx` usa `className="animate-pulse rounded-md bg-muted"`, mas `--color-muted` **não está definido** no tema Tailwind. Resultado: skeletons podem estar invisíveis ou com cor incorreta.

**Impacto:** Loading states (skeletons) não aparecem corretamente, criando experiência de "buraco" na UI durante carregamento.

---

## Objetivo

Adicionar `--color-muted` ao tema Tailwind ou substituir `bg-muted` por `bg-surface-variant`.

---

## Descrição

1. **Verificar** se `surface-variant` existe no tema e é adequado
2. **Se sim:** Substituir `bg-muted` por `bg-surface-variant` em skeleton.tsx
3. **Se não:** Adicionar ao globals.css:
   ```css
   :root {
     --color-muted: #E5E5EA; /* ou cor do design system */
   }
   ```

---

## Valor para o Negócio

Skeletons visíveis e consistentes com design system — essencial para UX de carregamento.

---

## Impacto no Usuário

- Loading states exibem corretamente
- Não há "buracos" visuais durante carregamento
