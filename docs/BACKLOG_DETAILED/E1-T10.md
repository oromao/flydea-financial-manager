# E1-T10 — Expandir Navegação Mobile

## Identificação

- **ID:** E1-T10
- **Tipo:** UX 🔴
- **Módulo:** Mobile / Mais
- **Título:** Expandir navegação mobile (MB-01)
- **Prioridade:** P0 (Crítico)
- **Complexidade:** Média

---

## Problema/Oportunidade

**Gap:** MB-01

67% dos módulos do sistema estão a 2+ taps de distância no mobile:
- Fluxo de Caixa
- Fechamento
- Recorrências
- Relatórios
- Logs
- Aprovações
- Alertas
- Perfil
- Orçamentos

O "Mais" na bottom nav abre uma página estática com cards, não um menu de navegação.

**Impacto:** Descoberta ruim — usuário não encontra funcionalidades importantes.

---

## Objetivo

Transformar "Mais" em um slide-up sheet (bottom sheet) com todos os módulos listados com ícones, acesso rápido.

---

## Descrição

1. **Referência:** Array `navItems` em `src/components/sidebar.tsx`
2. **Criar** componente SlideUpSheet em `src/components/ui/sheet.tsx` (shadcn/ui tem Sheet)
3. **Modificar** bottom-nav para abrir sheet ao clicar "Mais":
   ```tsx
   <Button variant="ghost" onClick={() => setSheetOpen(true)}>
     <MoreHorizontal className="w-5 h-5" />
   </Button>
   
   <Sheet open={sheetOpen} onOpenChange={setSheetOpen}>
     <SheetContent side="bottom">
       {/* Lista de módulos com ícones */}
     </SheetContent>
   </Sheet>
   ```
4. **Reaproveitar** `navItems` para gerar lista consistente

---

## Valor para o Negócio

Descoberta de módulos no mobile — acesso a 100% das funcionalidades em ≤2 taps.

---

## Impacto no Usuário

- Todos os módulos acessíveis em no máximo 2 taps
- Visual intuitivo (sheet desliza do bottom)
- Navegação consistente com design system
