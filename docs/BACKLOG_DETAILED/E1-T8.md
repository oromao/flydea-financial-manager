# E1-T8 — Esconder Tabela no Mobile

---

## Problema/Oportunidade

**Gap:** M-06

Na página de Movimentações, a tabela de transações e os cards mobile **renderizam simultaneamente no mobile**. Usuário vê conteúdo duplicado e precisa fazer scroll horizontal na tabela.

**Impacto:** UI confusa e poluída no mobile — experiência abaixo do esperado.

---

## Objetivo

Ocultar a tabela no mobile (renderizar apenas cards), mantendo a tabela visível no desktop.

---

## Descrição

1. **Local:** `src/app/movimentacoes/page.tsx`
2. **Encontrar** o container da tabela
3. **Adicionar** classe de ocultação:
   ```tsx
   <div className="hidden md:block">
     <Table>...</Table>
   </div>
   ```
4. **Garantir** que cards estão visíveis no mobile (`block md:hidden` ou já são o padrão)

---

## Valor para o Negócio

UX limpa no mobile — sem duplicação de conteúdo.

---

## Impacto no Usuário

- Apenas cards no mobile
- Apenas tabela no desktop
- Layout correto para cada viewport
