# E1-T5 — Adicionar Paginação em Logs

## Identificação

- **ID:** E1-T5
- **Tipo:** Bug 🔴 / Performance
- **Módulo:** Admin / Logs
- **Título:** Adicionar paginação em logs (L-01)
- **Prioridade:** P0 (Crítico)
- **Complexidade:** Média

---

## Problema/Oportunidade

**Gap:** L-01

A página de Logs (`/admin/logs`) renderiza **todos os logs de uma vez** via `filteredLogs.map()`. Com 100+ logs, a página fica extremamente lenta e longa.

**Impacto:** Performance degradada, experiência ruim, possível crash em volumes altos.

---

## Objetivo

Implementar paginação (25 por página) ou infinite scroll.

---

## Descrição

1. **Local:** `src/app/admin/logs/page.tsx`
2. **Adicionar estado:**
   ```typescript
   const [currentPage, setCurrentPage] = useState(1);
   const pageSize = 25;
   ```
3. **Modificar renderização:**
   ```typescript
   const paginatedLogs = filteredLogs.slice(
     (currentPage - 1) * pageSize,
     currentPage * pageSize
   );
   ```
4. **Adicionar controles de paginação** (botões Anterior/Próxima + números)
5. **Se API suporta:** Usar server-side pagination com `skip/take`

---

## Valor para o Negócio
