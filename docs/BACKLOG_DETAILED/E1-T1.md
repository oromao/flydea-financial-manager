## Identificação

- **ID:** E1-T1

- **Módulo:** Recorrências
- **Título:** Implementar delete de recorrências (R-01, R-02)
- **Prioridade:** P0 (Crítico)
- **Complexidade:** Baixa

---

## Problema/Oportunidade

**Gaps:** R-01 (delete button sem onClick), R-02 (handleDelete nem existe)

O botão de delete na página de Recorrências (`/recorrencias`) não funcional. Ao clicar, nada acontece porque:
1. O botão não tem handler de onClick atribuído
2. A função `handleDelete` não foi implementada

**Impacto:** Usuário não consegue excluir recorrências não utilizadas, corroendo confiança no sistema.

---

## Objetivo

Fazer o delete de recorrências funcionar com:
- Confirmação antes de excluir (via useConfirm)
- Chamada de API para DELETE
- Atualização da lista após sucesso

---

## Descrição

1. **Local:** `src/app/recorrencias/page.tsx`
2. **Ações necessárias:**
   - Adicionar `onClick={() => handleDelete(rec.id)}` no botão de delete
   - Implementar função `handleDelete` que:
     - Use `useConfirm()` para confirmação
     - Chame `DELETE /api/recurrences/[id]`
     - Atualize a lista de recorrências após sucesso
     - Trate erros com `useToast().error()`

## Observações de Decisão

**[DECISÃO]:** O que acontece com transações já geradas por esta recorrência quando ela é deletada?

Opções consideradas:
1. **Manter transações geradas** — são registros históricos, devem permanecer
2. **Cascade delete** — Deletar todas as transações geradas

**Decisão:** Opção 1 — Manter transações geradas. A recorrência é apenas o "template", as transações geradas são fatos consumados. Registrar esta decisão em `docs/DECISIONS_LOG.md`.
