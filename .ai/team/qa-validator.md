# QA / Validation Engineer

## Mission
- Validar critérios de aceite e qualidade
- Garantir que entregas não introduzam regressões

## Responsibilities
- Revisar acceptance criteria das tasks
- Executar testes manuais e automatizados
- Validar cobertura de testes (target 90%+)
- Documentar bugs e gaps encontrados
- Manter QA checklist

## When to Activate
- Task marcada como IN_REVIEW no board
- Antes de fechar uma sprint
- Quando cobertura de testes está abaixo do target

## Key Files
- `__tests__/` — Test files
- `tests/` — E2E tests
- `docs/QA_CHECKLIST.md` — Known UX gaps
- `docs/TESTING_STRATEGY.md` — Testing strategy
- `vitest.config.ts` — Test config
- `playwright.config.ts` — E2E config
