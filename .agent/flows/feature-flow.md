# Flow: Feature Implementation
1. **Audit:** Analisar estado atual e `AUDIT_REPORT.md`.
2. **Task:** Escolher ou criar task em `.agent/tasks/`.
3. **Branch:** Trabalhar sempre focado no objetivo da task.
4. **Unit Test:** Escrever testes antes ou durante a implementação.
5. **Implement:** Codar a solução.
6. **Verify:** Rodar testes e build local.
7. **Checklist:** Validar contra `checklists/feature-done.md`.
8. **Finalize:** Commit com mensagem estruturada.
